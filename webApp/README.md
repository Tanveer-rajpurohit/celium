# Celium website

Reserved for the future Celium website and installable web app.

- `src/`: website application code, including pages, components, and browser integrations.
- `public/`: files served publicly, such as icons and images. No secrets.

No framework, dependencies, build command, or deployment has been configured. Choose them when website implementation starts. This directory is not an Android or desktop Gradle module.

See [the repository structure](../structure.md) for shared-code and release boundaries.
